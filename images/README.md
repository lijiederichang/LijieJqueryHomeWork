# 图片存储目录说明

## 目录用途
此目录用于存储用户上传的卡片图片。

## 图片命名规则
- 格式：`card_{timestamp}.{extension}`
- 示例：
  - `card_1702567890123.jpg`
  - `card_1702567890124.png`
  - `card_1702567890125.gif`

## 支持的图片格式
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- WebP (.webp)

## 文件大小限制
- 最大文件大小：5MB
- 建议尺寸：宽度不超过 2000px

## 示例图片
为了演示，您可以在此目录中放置以下示例图片：

1. `game1.jpg` - 电子竞技相关图片
2. `game2.jpg` - 游戏开发相关图片

## 注意事项
1. 确保服务器对 `images/` 目录有写入权限
2. 在生产环境中，建议使用对象存储服务（如阿里云OSS、腾讯云COS等）
3. 定期清理未使用的图片文件
4. 考虑实现图片压缩功能以节省存储空间

## 本地开发
在本地开发时，图片路径会存储在 localStorage 中，格式为：
```
images/card_1702567890123.jpg
```

前端代码会直接使用此路径显示图片。
